# Changelog

All notable changes to the reference implementation are documented in this file.

## 1.0.0 — 2026-09-15

- Added the complete SentrySem protocol implementation.
- Added deterministic CIFAR-10 partitioning, view generation, and frozen ResNet-18 feature extraction.
- Added threshold calibration with disjoint CAL-TUNE and CAL-VALIDATE identities.
- Added the 1-, 8-, and 64-candidate post-selection boundary experiment.
- Added proposal-audit allocation selection and the frozen 256/768 configuration.
- Added fixed-audit, Bonferroni, same-evidence, unverified-search, and sequential comparison methods.
- Added partial-cache, missing-class, strong-view, and novel-source stress evaluations.
- Added source-identity cluster bootstrap intervals and logical traffic accounting.
- Added all manuscript figures, immutable paper results, frozen inputs, validation checks, tests, and PyCharm run configurations.
